# Security Policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch. This
project does not currently maintain separate release branches.

## Reporting a vulnerability

Do not report suspected vulnerabilities through a public issue, discussion, or
pull request.

Use [GitHub private vulnerability reporting][report] to share:

- A description of the vulnerability and its potential impact
- Reproduction steps or a proof of concept
- Affected files, versions, or commits
- Any suggested mitigation, if known

You should receive an acknowledgement within seven days. Maintainers will
coordinate investigation, remediation, and disclosure with the reporter. Please
allow a reasonable remediation period before public disclosure.

Never include credentials, tokens, private session data, or information about
unrelated third parties in a report.

[report]: https://github.com/Evangelink/copilot-session-map-canvas/security/advisories/new
